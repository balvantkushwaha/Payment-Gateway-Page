# Payment Gateway Page

This is a simple **Payment Gateway Page** created using HTML and CSS. I developed this project as part of my frontend development learning journey to practice webpage design and responsive layouts.

- CSS3

- Responsive web design
- Basic payment page layout
- Beginner-friendly frontend project
